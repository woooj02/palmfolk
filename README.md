# Palmfolk

A hands-only puzzle adventure for Meta Quest 3 and 3S. Tiny travelers walk across your fingers, and the bridges
they build keep the shape of your hand after you let go.

Entry for the Meta VR Start Developer Competition 2026 (Gaming track, New Experience division).

Status: M1 slice 0 source prepared on Linux; Unity import, Android build and Quest 2
verification are pending on Windows. No headset behavior is verified yet.

Open the repository root with **Unity 6000.0.66f2 on Windows**, with Android Build
Support, OpenJDK and Android SDK & NDK Tools installed. Follow
[`docs/slice-0-quest2.md`](docs/slice-0-quest2.md) to generate the scene, build and test.

Work follows [`docs/build-plan.md`](docs/build-plan.md) and
[`docs/requirements-v1.2.md`](docs/requirements-v1.2.md). M1 only, one slice at a time.
See [`docs/m1-progress.md`](docs/m1-progress.md) for decisions and verification status.
